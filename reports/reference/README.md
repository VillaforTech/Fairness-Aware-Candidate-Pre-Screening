# Reference reports

These JSON reports are evidence snapshots generated by the supported CLI. They
contain metrics, split provenance, subgroup cell counts, dependency versions,
and uncertainty intervals. Model binaries, prediction rows, and serving-policy
files stay local and are not committed.

Rebuild the current reference from the bundled raw UCI files:

```bash
uv run fairness data preprocess \
  --input-dir data/raw/adult \
  --output-path data/processed/adult/adult_model_ready.csv

uv run fairness audit \
  --model xgb \
  --seed 42 \
  --data-path data/processed/adult/adult_model_ready.csv \
  --output-dir reports/reference \
  --run-id xgb-seed-42-v1 \
  --bootstrap-samples 500
```

The default policy gate is expected to reject this benchmark on DI and SPD.
That rejection is part of the result, not a broken run.
