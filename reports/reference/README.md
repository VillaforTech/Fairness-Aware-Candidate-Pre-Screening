# Reference evidence

The committed reference is a five-seed XGBoost stability study generated by the
supported CLI from the bundled UCI Adult files. It contains:

- `stability.json`: seed-level metric and threshold distributions, comparability
  conditions, governance outcomes, and the deterministic worst-seed ranking;
- `report.json`: the complete seed-4 audit selected by that ranking;
- `monitoring.json`: the aggregate-only held-out monitoring baseline for seed 4;
- `audit.html`: a self-contained rendering of the seed-4 report with the
  five-seed stability context.

Model binaries, prediction rows, and serving-policy files are intentionally not
committed. They are reproducible with the commands below.

Rebuild the published evidence from the clean source commit recorded inside the
report:

```bash
uv run fairness data preprocess \
  --input-dir data/raw/adult \
  --output-path data/processed/adult/adult_model_ready.csv

uv run fairness study \
  --model xgb \
  --seeds 0,1,2,3,4 \
  --data-path data/processed/adult/adult_model_ready.csv \
  --output-dir /tmp/fairness-reference \
  --study-id xgb-five-seed-v2 \
  --bootstrap-samples 500
```

The study writes five complete seven-file bundles beneath `runs/`, then writes
`stability.json` and a combined `audit.html` at the study root. The public
snapshot keeps the ranked worst-seed report and monitoring baseline alongside
those aggregate artifacts.

All five runs are expected to fail the default governance gate. That is the
result: the pipeline completed, the evidence is valid, and the configured
policy rejected every candidate bundle.
